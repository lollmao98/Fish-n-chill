-A game about fishing. before complete darkness ( 20 sec limit). and you have to catch 20 fish by clicking on it . knowing there is only a 50 precent chance of catching it. and if you don't catch 20 fish you lose.

-to run the game 
 download the fish n chill in the repo zip 
   extract it and run fish n chill html 
   then click run game and enjoy
 or
  go to the itch page https://lollmao98.itch.io/fish-n-chill

-This game was made in godot . and most of the assest are hand drawn by me. the rest are leant from my freinds.

-The reason I made this game was because I was playing stardew valley and fishing. and I thought man I wish it was more face paced and reaction speed paced.
So I did just that with some tinkering and idea changing of before black out fishing.
